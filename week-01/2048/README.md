# 🔢 2048

같은 숫자 타일을 밀어서 합치는 **숫자 퍼즐 게임**이에요.
2 + 2 = 4, 4 + 4 = 8 … 이렇게 계속 합쳐서 **2048** 타일을 만들면 성공이에요.

**▶ 플레이: https://hyeonseora.github.io/QUEST-TRACK-2/week-01/2048/**

## 하는 방법

- **키보드**: 방향키(`←` `↑` `→` `↓`)로 모든 타일을 한쪽으로 밀어요.
- **휴대폰**: 화면을 손가락으로 쓸어서(스와이프) 밀어요.
- 같은 숫자 두 개가 부딪히면 하나로 합쳐지고, 그 숫자만큼 점수가 올라가요.
- 한 번 밀 때마다 빈칸에 새 타일이 하나 나와요.
- 더 이상 밀 수 없으면 게임이 끝나요.

## 기능

- 최고 점수가 브라우저에 저장돼요.

## 내 컴퓨터에서 실행하기

이 폴더의 `index.html` 을 더블클릭하면 브라우저에서 바로 열려요.

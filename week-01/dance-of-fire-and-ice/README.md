# 🔥 얼불춤 (Fire & Ice)

불 행성과 얼음 행성이 번갈아 돌며 길을 따라가는 **리듬 게임**이에요.
음악 박자에 맞춰 키를 누르면 돌고 있던 행성이 다음 칸에 내려앉아요.

**▶ 플레이: https://hyeonseora.github.io/QUEST-TRACK-2/week-01/dance-of-fire-and-ice/**

## 스테이지

| # | 이름 | 난이도 | BPM |
|---|---|---|---|
| 1 | 새벽 별 (DAWN STAR) | ★ | 112 |
| 2 | 물결 (RIPPLE) | ★★ | 124 |
| 3 | 불씨와 서리 (EMBER & FROST) | ★★★ | 136 |
| 4 | 폭풍 (TEMPEST) | ★★★★ | 150 |
| 5 | 초신성 (SUPERNOVA) | ★★★★★ | 172 |

## 조작

| 화면 | 키 |
|---|---|
| 타이틀 | `Space` / `Enter` → 스테이지 선택 |
| 스테이지 선택 | `←` `→` 또는 `1`~`5` 로 고르기 · `A` 자동 플레이 켜기/끄기 · `Space` / `Enter` 시작 |
| 플레이 중 | 아무 키 또는 화면 클릭/터치 → 박자 맞추기 · `Esc` 일시정지 |
| 일시정지 | `Esc` 계속하기 · `R` 다시 하기 |
| 결과 | `R` 다시 하기 · `Space` / `Enter` 다음 스테이지 |

## 기능

- **싱크 보정**: 내 컴퓨터·이어폰의 소리 지연에 맞춰 판정 타이밍을 조절할 수 있어요.
- **자동 플레이**: 스테이지가 어떻게 흘러가는지 미리 볼 수 있어요.
- **최고 기록 저장**: 스테이지마다 최고 기록이 브라우저에 저장돼요.
- 음악은 파일이 아니라 Web Audio 로 그 자리에서 연주돼요.

## 내 컴퓨터에서 실행하기

이 폴더의 `index.html` 을 더블클릭하면 브라우저에서 바로 열려요.

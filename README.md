## 폴더 구조

```
QUEST-TRACK-2/
├─ README.md                  ← 지금 보고 있는 파일
├─ CLAUDE.md                  ← Claude 에게 주는 작업 규칙
├─ 진도.md                    ← 수업마다 남기는 진도 기록
├─ week-01/                   ← 학원 수업 1주차
│  ├─ dance-of-fire-and-ice/  ← 얼불춤
│  ├─ 2048/                   ← 2048
│  └─ game-menu/              ← 게임 모음 메뉴
└─ home-projects/             ← 집에서 만든 작품
   └─ stellar-miner/          ← 스텔라 마이너
```

- `week-01` ~ `week-11`: 학원 수업 주차별 작업
- `home-projects`: 수업이 아닌, 집에서 만든 작품 (작품마다 폴더 하나)

## 내 컴퓨터에서 실행하기

1. 이 저장소를 내려받아요 (초록색 **Code** 버튼 → **Download ZIP**, 또는 `git clone`).
2. 하고 싶은 게임 폴더에 들어가서 `index.html` 을 더블클릭해요.
3. 브라우저에서 게임이 열려요. 설치할 것은 없어요.

> 게임 기록은 브라우저에 저장돼요. 다른 브라우저로 열면 처음부터 시작해요.

## 폴더 구조

```
QUEST-TRACK-2/
├─ README.md                  ← 지금 보고 있는 파일
├─ CLAUDE.md                  ← Claude 에게 주는 작업 규칙
├─ 진도.md                    ← 수업마다 남기는 진도 기록
├─ week-01/                   ← 학원 수업 1주차
│  ├─ dance-of-fire-and-ice/  ← 얼불춤
│  ├─ 2048/                   ← 2048
│  └─ game-menu/              ← 게임 모음 메뉴
├─ week-02/                   ← 학원 수업 2주차
│  └─ minecraft/              ← 마인크래프트
├─ week-03/                   ← 학원 수업 3주차
│  └─ haunted-maze/           ← 망령의 미로
├─ week-04/                   ← 학원 수업 4주차
│  └─ rng/                    ← 운명의 굴림
└─ home-projects/             ← 집에서 만든 작품
   ├─ beat-runner/            ← 비트 러너
   ├─ haunted-maze/           ← 망령의 미로
   ├─ rhythm-fighter/         ← 리듬 파이터
   ├─ seventh-period/         ← 제7교시
   └─ stellar-miner/          ← 스텔라 마이너
```

- `week-01` ~ `week-11`: 학원 수업 주차별 작업
- `home-projects`: 수업이 아닌, 집에서 만든 작품 (작품마다 폴더 하나)

## 내 컴퓨터에서 실행하기

1. 이 저장소를 내려받아요 (초록색 **Code** 버튼 → **Download ZIP**, 또는 `git clone`).
2. 하고 싶은 게임 폴더에 들어가서 `index.html` 을 더블클릭해요.
3. 브라우저에서 게임이 열려요. 설치할 것은 없어요.

> 게임 기록은 브라우저에 저장돼요. 다른 브라우저로 열면 처음부터 시작해요.

## exe 로 실행하기 (윈도우)

1. 위 표의 `exe` 링크나 [Releases](https://github.com/HyeonSeoRA/QUEST-TRACK-2/releases/latest) 에서 하고 싶은 게임의 `.exe` 를 받아요.
2. 받은 파일을 더블클릭하면 게임 창이 열려요. 설치할 것은 없어요.
3. `F11` 은 전체 화면, `F12` 는 개발자 도구예요.

> - 서명이 없는 프로그램이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있어요. **추가 정보 → 실행** 을 누르면 열려요.
> - 게임 기록은 exe 마다 따로 저장돼요. (브라우저에서 한 기록과는 따로예요)
> - 글꼴은 인터넷에서 불러와요. 인터넷이 없으면 기본 글꼴로 보여요.

# 🏮 등불 원정대 (Lantern Quest)

해를 삼킨 잿빛 왕에게서 빛을 되찾으러 떠나는 **도트 2D 턴제 RPG**예요.
동료 3명을 골라 네 개의 땅을 지나고, 땅마다 기다리는 우두머리를 쓰러뜨려요.

**▶ 플레이: https://hyeonseora.github.io/QUEST-TRACK-2/week-05/lantern-quest/**

## 하는 방법

1. **새 여정**을 누르고, 6명 중에서 함께 떠날 동료 **3명**과 **난이도**(쉬움 · 보통 · 어려움)를 골라요.
2. 지도에서 빛나는 칸을 눌러 앞으로 가요. 어느 길로 갈지는 직접 골라요.
3. 전투에서는 **속도가 빠른 순서**대로 한 명씩 움직여요. 공격 · 기술 · 물건 · 방어 · 도망 중에서 고르고, 적을 눌러 대상을 정해요.
4. 땅의 마지막 칸에 있는 **우두머리**를 쓰러뜨리면 다음 땅으로 가요. 네 번째 땅의 잿빛 왕을 쓰러뜨리면 끝!

## 동료 6명

| 직업 | 역할 | 특징 |
|---|---|---|
| 🛡️ 기사 레온 | 방패 | 체력과 방어가 높아요. 도발로 적의 공격을 자기에게 모아요 |
| 🔮 마법사 에르달 | 마법 공격 | 불 · 얼음 · 번개 마법으로 약점을 찔러요 |
| ✨ 성직자 세라 | 회복 | 치유, 정화, 부활. 빛 마법은 망령에게 강해요 |
| 🗡️ 도적 키라 | 치명타 | 가장 빨라요. 급소 찌르기, 독, 금화 훔치기 |
| 🏹 궁수 린 | 원거리 | 빗나가지 않는 화살, 화살비, 방어를 뚫는 화살 |
| ⚗️ 연금술사 파샤 | 방해 | 산성으로 방어를 깎고, 폭탄과 물약을 던져요 |

직업마다 기술이 6개씩 있고, 레벨 1 · 3 · 5 · 7 · 10에 새 기술을 배워요. (최고 레벨 15)

## 등불 게이지와 필살기

싸울수록 왼쪽 위의 **등불 게이지**가 차올라요. (때리면, 맞으면, 치명타 · 약점이면 더 많이)
가득 차면 명령 6번 **필살기**를 쓸 수 있어요. 화면을 가로지르는 컷인 연출과 함께 직업마다 다른 큰 기술이 나가요.
게이지는 다음 전투로 이어지니까, 우두머리를 위해 아껴 둘 수도 있어요.

| 직업 | 필살기 | 효과 |
|---|---|---|
| 기사 | 성채의 맹세 | 모든 적에게 빛의 일격 + 동료 모두 회복 · 방어↑ |
| 마법사 | 별 무너뜨리기 | 적마다 가장 아픈 속성(불 · 얼음 · 번개)으로 내리친다 |
| 성직자 | 새벽의 기적 | 쓰러진 동료를 모두 일으키고 크게 회복 + 재생 |
| 도적 | 천 개의 그림자 | 무작위 적을 8번 벤다 |
| 궁수 | 별빛 화살 | 방어를 뚫는 거대한 화살 + 기절 |
| 연금술사 | 대연성 | 모든 적에게 어둠 + 독 · 화상 · 방어↓ · 공격↓ |

## 유물 18종

강적과 우두머리를 이기면 유물 3개 중 하나를 골라 가져요. 보물 상자와 상인에게서도 얻을 수 있어요.
유물은 그 여정이 끝날 때까지 계속 효과가 있어서, 판마다 다른 조합이 만들어져요.
(꺼지지 않는 불씨, 서리 결정, 번개 깃털, 오래된 등잔, 흡혈 송곳니, 거북 등껍질, 금화 주머니, 현자의 안경, 부활의 씨앗, 마나 꽃, 가시 갑옷 조각, 행운 동전, 약초 주머니, 사냥꾼의 표식, 빛의 성배, 상인의 인장, 독사의 이빨, 용기의 깃발)

## 변종 몬스터

가끔 몬스터 하나가 빛을 두르고 나와요. 대신 경험치와 금화를 1.7배 줘요.

| 변종 | 특징 |
|---|---|
| 단단한 | 체력과 방어가 높다 |
| 날쌘 | 빠르고 잘 피한다 |
| 불타는 | 때리면 화상을 입힌다 |
| 흡혈하는 | 때린 만큼 체력을 빨아들인다 |
| 거대한 | 몸집이 1.25배, 체력 2배, 힘이 세다 |

## 이야기와 도감

- 여정을 시작하면 해를 빼앗긴 세상의 이야기가 나와요.
- 우두머리 앞에서는 우두머리와 원정대가 한마디씩 주고받아요.
- 시작 화면의 **몬스터 도감**에 지금까지 만난 몬스터가 모여요. 한 번 쓰러뜨리면 능력치와 약점까지 보여요. 도감은 여정이 끝나도 남아요.

## 네 개의 땅

| 장 | 땅 | 몬스터 | 강적 | 우두머리 |
|---|---|---|---|---|
| 1장 | 이끼 숲 | 이끼 슬라임, 가시 멧돼지, 독버섯 꼬마, 숲 늑대 | 고목 수호자 | 거미 여왕 실타래 |
| 2장 | 잊힌 모래 왕국 | 모래 전갈, 떠도는 미라, 사막 독수리, 진흙 거인 | 저주받은 파라오 | 모래 왕뱀 아펩 |
| 3장 | 서리 수정 동굴 | 얼음 박쥐, 서리 도깨비불, 수정 게, 펭귄 창기사 | 설인 우두머리 | 서리 용 니블 |
| 4장 | 잿불 성채 | 불꽃 임프, 해골 근위병, 용암 슬라임, 그림자 마법사 | 지옥 사냥개 | 잿빛 왕 |

어디서나 가끔 **황금 슬라임**(금화를 잔뜩 주지만 도망쳐요)과 **상자 괴물**이 나와요.
우두머리는 체력이 절반 아래로 떨어지면 **2단계**가 되어 한 턴에 두 번 움직여요.

## 지도의 칸

| 칸 | 하는 일 |
|---|---|
| ⚔️ 전투 | 몬스터 무리와 싸워요 (가끔 변종이 섞여 있어요) |
| 💀 강적 | 강한 적. 이기면 좋은 장비와 유물을 줘요 |
| 🔥 모닥불 | 쉬기(회복) · 수련(경험치) · 무기 벼리기(강화) 중 하나 |
| 💰 떠돌이 상인 | 물약 · 장비 · 유물을 사고, 남는 장비를 팔아요 |
| ❓ 수상한 곳 | 사건 10가지 중 하나 (제단, 음유시인, 별똥별, 그림자 상인…) |
| 📦 보물 상자 | 금화 · 장비 · 유물. 가끔 상자 괴물! |

## 전투 규칙

- **속성**: 물리 · 불 · 얼음 · 번개 · 빛 · 어둠 · 독. 약점을 찌르면 1.5배, 저항하면 절반이에요. 한 번 알아낸 약점은 대상 정보에 기억돼요.
- **상태**: 독 · 화상 · 출혈(매 턴 피해), 빙결 · 기절(한 턴 쉼), 공격↑↓ · 방어↑↓ · 속도↑↓, 재생, 도발, 회피↑
- **치명타**: 1.7배 피해. 화면이 흔들려요.
- **방어**: 받는 피해 절반 + 마나 조금 회복
- **쓰러짐**: 쓰러진 동료는 모닥불, 부활 기술, 불사조 깃털로 일으켜요. 모두 쓰러지면 여정이 끝나요.
- **힘 모으기**: 어떤 우두머리는 한 턴 동안 힘을 모은 뒤 큰 공격을 해요. 몸이 분홍빛으로 빛나면 대비하세요!

## 장비

무기 · 갑옷 · 장신구 3칸이에요. 무기는 직업 전용이고, 갑옷과 장신구는 누구나 입어요.
등급은 **보통 · 고급 · 희귀 · 전설** 4가지예요. 전설 장비에는 흡혈, 가시, 재생, 마나 샘, 선제, 불꽃, 성스러움, 처형 중 하나의 특별한 힘이 붙어요.
지도 위 **원정대** 버튼에서 장비를 바꾸고 물약을 쓸 수 있어요.

## 조작

| 키 | 하는 일 |
|---|---|
| 마우스 | 칸 고르기, 명령 고르기, 적 누르기 |
| 1 ~ 6 | 전투 명령 바로 고르기 (6 = 필살기) |
| 방향키 + Enter | 고르기 |
| Esc | 뒤로 |
| A | 자동 전투 켜기 / 끄기 |

| P | (지도에서) 원정대 창 |

## 그 밖의 기능

- 칸을 하나 지날 때마다 자동 저장돼요. 시작 화면의 **이어하기**로 계속할 수 있어요.
- 설정에서 효과음 · 음악 크기, 전투 속도, 화면 흔들림, **글자 · 메뉴 크기**(작게 · 보통 · 크게)를 바꿀 수 있어요.
- 지금까지의 원정 횟수, 승리 횟수, 쓰러뜨린 적 수가 기록돼요.

## 만든 방법

- HTML + JavaScript 로 만들었고, 외부 라이브러리는 쓰지 않았어요. 글꼴만 [갈무리](https://github.com/quiple/galmuri) 도트 글꼴을 불러와요.
- **그림은 모두 코드로 그려요.** 그림 파일이 하나도 없어요.
- 영웅마다 그림이 6장이에요: 서 있기(숨쉬기 2장), 무기 들기, 휘두르기, 주문 외우기, 맞기. 공격할 때 무기를 들었다가 휘두르고, 맞으면 몸을 젖혀요. 몬스터는 공격할 때 늘어나고 맞으면 찌그러져요.
- **도트 그림**: 영웅 6명은 24 x 32 칸 그림을 **한 칸씩 직접 찍어서** 그렸어요 (`js/heroart.js`). 글자 하나가 한 칸이고, 머리카락 · 얼굴 · 옷 주름 · 명암을 칸마다 정했어요. 팔과 무기는 따로 그려서 동작마다 위치와 각도를 바꿔요. 화면 전체는 960 x 540 도트로 그린 다음, 픽셀을 네모 블록 그대로 창 크기에 맞게 키워요.
- 전투에 들어갈 때 화면이 비스듬히 갈라지는 전환, 우두머리 등장과 치명타 때 카메라 확대, 땅마다 흐르는 안개, 화면 가장자리를 어둡게 하는 효과가 있어요.
- 창 크기가 바뀌면 그림과 글자가 함께 커지고 작아져서 화면에 꽉 맞아요. (16:9 비율 유지)
- 처음 열 때 모든 그림을 미리 그려 두느라 몇 초 동안 진행 막대가 보여요.
- 효과음과 배경 음악 7곡은 Web Audio 로 그 자리에서 만들어요 (소리 파일 없음).

| 파일 | 하는 일 |
|---|---|
| `js/gfx.js` | 그림 도구 (점, 타원, 다각형, 자동 그림자·반사광·테두리) |
| `js/heroart.js` | 영웅 6명의 도트 그림 (한 칸씩 찍은 그림, 팔·무기, 동작 6가지) |
| `js/sprites.js` | 몬스터 27종, 아이콘 그림 |
| `js/backgrounds.js` | 땅마다 다른 배경과 떠다니는 것들 (반딧불, 모래, 눈, 불티) |
| `js/data.js` | 직업, 기술, 몬스터, 땅, 물건, 장비 |
| `js/extra.js` | 필살기, 변종, 난이도, 유물, 도감 설명, 이야기 |
| `js/state.js` | 동료 능력치, 레벨, 장비 만들기, 지도 만들기, 저장 |
| `js/battle.js` | 전투 규칙 (순서, 피해 계산, 상태, 몬스터 생각, 보상) |
| `js/battleui.js` | 전투 화면 (그리기, 명령, 대상 고르기, 보상 창) |
| `js/fx.js` | 기술 연출 (불덩이, 번개, 빛기둥, 눈보라, 일식…) |
| `js/audio.js` | 효과음과 배경 음악 |
| `js/scenes.js` | 시작, 동료 고르기, 이야기, 지도, 상점, 모닥불, 사건, 보물, 유물 고르기, 우두머리 대화, 도감, 원정대 창, 끝 |

## 내 컴퓨터에서 실행하기

이 폴더의 `index.html` 을 더블클릭하면 브라우저에서 바로 열려요.

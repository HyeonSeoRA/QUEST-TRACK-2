# 🎧 비트 러너 · 잊혀진 선율 (Beat Runner)

망각의 군주가 세상의 노래를 빼앗아 갔어요. **리듬의 검사 리아**와 **요정 루미**가 세 개의 선율의 수정을 되찾으러 떠나는
**리듬 액션 RPG** 예요.
전투는 횡스크롤 리듬게임이에요. 박자에 맞춰 공중과 땅의 적을 베어요.
전투 밖에서는 세계 지도를 여행하고, 레벨을 올리고, 상점에서 장비를 사서 강해져요.

- **Phaser 3** 로 만들었어요.
- 화면은 **480 x 270 픽셀 아트**이고, 모니터에 맞춰 2~4배 크기로 선명하게 그려요.
- **2.5D 그래픽**: 바닥은 멀어질수록 좁아지는 원근 바닥이고, 풀숲·바위·수정·묘비 같은 소품이 여러 깊이에 서 있어요. 먼 곳은 작고 느리게, 가까운 곳은 크고 빠르게 지나가며 안개가 깊이를 만들어요.
  카메라가 주인공 주위를 천천히 돌아서(주인공이 달리는 줄은 그대로) 먼 곳일수록 옆으로 더 움직이고, 장소마다 빛 색이 캐릭터를 물들이고, 공중의 적·요정·보스에게도 바닥 그림자가 생겨요.
- 그림과 음악은 모두 **코드로 그리고 연주**해서, 이미지·음악 파일이 하나도 없어요.

**▶ 플레이: https://hyeonseora.github.io/QUEST-TRACK-2/home-projects/beat-runner/**

## 조작

| 키 | 하는 일 |
|---|---|
| `D` `F` (또는 `↑`) | 공중의 적 베기 |
| `J` `K` (또는 `↓`) | 땅의 적 베기 |
| `SPACE` | 버스트 (게이지가 차면 16박자 동안 점수 2배, 보스 피해 1.5배) |
| `ESC` | 일시정지 / 메뉴 |
| 방향키, `Enter`, `Esc` | 메뉴 고르기 · 확인 · 취소 (마우스로 눌러도 돼요) |
| 터치 | 전투 중 화면 위쪽 = 공중, 아래쪽 = 땅 |

## 모험의 흐름

1. **제목 화면**에서 `새로 시작` → 프롤로그 이야기
2. **세계 지도**에서 다음 장소로 걸어가요. 스테이지를 깨야 다음 길이 열려요.
3. **하르모니아 마을**에서 상점·장비·상태·기록(저장)
4. 각 장의 마지막에는 **보스**가 있어요. 노래가 끝나기 전에 보스의 HP를 0으로 만들어야 이겨요.
5. 세 보스를 모두 물리치면 **엔딩**과 크레딧

| 장 | 장소 | 스테이지 | 보스 |
|---|---|---|---|
| 1장 | 속삭이는 숲 (낮) | 숲의 입구 · 반딧불 오솔길 | 고목의 수호자 |
| 2장 | 수정 동굴 | 푸른 수정길 · 울림의 호수 | 수정 비룡 |
| 3장 | 망각의 성 (밤) | 무너진 성문 · 달빛 회랑 | 망각의 군주 |

스테이지마다 **보통 / 어려움**을 고를 수 있어요. 어려움은 노트가 많지만 보상이 1.5배예요.

## RPG 요소

- **레벨** (최대 20): 경험치를 모으면 최대 HP·공격력·방어력이 올라요. 져도 경험치를 조금 받아요.
- **공격력**: 보스에게 주는 피해. PERFECT 일수록, 콤보가 길수록 세게 들어가요.
- **방어력 / 최대 HP**: 놓쳤을 때 받는 피해가 줄고, 더 오래 버텨요.
- **골드**: 적을 벨 때마다 떨어져요. 상점에서 무기·방어구·장신구를 사요.
- **장신구**: 판정이 너그러워지는 깃털, 버스트가 빨리 차는 부적, 골드를 더 주는 동전, 물약 회복 2배 반지 등
- **대장간 강화**: 마을의 대장간에서 무기·방어구를 +1 ~ +10 까지 강화해요. 골드와 **마정석**이 들고, 높은 단계일수록 성공 확률이 낮아져요 (실패해도 단계는 그대로).
- **마정석**: 스테이지를 깨면 받아요 (어려움·보스·S 랭크면 더 많이). 가끔 나오는 **빛나는 엘리트 적**을 베면 떨어뜨리기도 해요. 엘리트는 골드도 3배!
- **콤보 오라**: 50 콤보부터 금빛, 100 콤보부터 무지갯빛 기운이 리아를 감싸요.
- **보스 전리품**: 보스를 처음 쓰러뜨리면 특별한 장비를 얻어요.
- 모험은 자동으로 브라우저에 저장돼요. 다음에 `이어하기` 로 계속할 수 있어요.

## 판정

- **PERFECT**(±45ms) · **GREAT**(±90ms) · **GOOD**(±135ms) · **MISS**
- GREAT·GOOD 아래에 **FAST**(일찍) / **SLOW**(늦게) 가 떠요.
- 늘 늦게 / 일찍 친다고 나오면 **설정 → 판정 맞추기** 로 조절해요.
- 렉이 있으면 **설정 → 그래픽** 을 `빠르게` 로 바꿔 보세요. (빠르게 2배 · 보통 3배 · 선명하게 4배 크기로 그려요)
- 랭크: S(정확도 95%↑) · A(88%↑) · B(78%↑) · C(65%↑) · D / 지면 F

## 파일

```
beat-runner/
├─ index.html      ← 여기를 열면 게임 시작
└─ js/
   ├─ util.js      ← 공통 상수, 저장, 카메라·장면 전환
   ├─ font.js      ← 글꼴 불러오기, 글자 도우미
   ├─ pixel.js     ← 도트 그림 엔진 (빛과 그늘, 자연스러운 질감, 울퉁불퉁한 가장자리, 미리 굽는 흐림)
   ├─ data.js      ← 아이템, 스테이지, 이야기 대사, 능력치 계산
   ├─ art.js       ← 리아·루미·적·보스·초상화·아이콘 그림
   ├─ bg.js        ← 장소별 배경 (원근 바닥 셰이더, 깊이별 소품, 안개, 빛줄기)
   ├─ audio.js     ← 악기(플루트·종·하프 등)와 효과음
   ├─ songs.js     ← 곡과 채보 만들기, 배경 음악
   ├─ ui.js        ← RPG 창, 메뉴, 게이지, 대화창
   ├─ menu.js      ← 제목, 세계 지도, 마을, 상점·장비·상태·설정 창
   ├─ story.js     ← 이야기 장면, 엔딩 크레딧
   ├─ play.js      ← 전투 (판정, 보스, 버스트)
   ├─ result.js    ← 결과와 보상 (레벨 업)
   └─ main.js      ← Phaser 게임 시작
```

> Phaser 와 글꼴은 인터넷(cdnjs, Google Fonts)에서 불러와요. 인터넷이 연결돼 있어야 실행돼요.

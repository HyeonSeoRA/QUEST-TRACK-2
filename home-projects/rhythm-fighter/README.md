# ⚔️ 리듬 파이터 (Rhythm Fighter)

어둠에 잠긴 땅을 원정하는 **다크 판타지 리듬 액션 게임**이에요.
왼쪽에서는 **리듬게임**을 하고, 오른쪽에서는 **기사와 몬스터가 싸워요.**
노트를 박자에 맞춰 치면 기사가 검기를 날려 몬스터를 베고, 놓치면 몬스터가 기사를 공격해요.

**▶ 플레이: https://hyeonseora.github.io/QUEST-TRACK-2/home-projects/rhythm-fighter/**

## 하는 방법

| 키 | 하는 일 |
|---|---|
| `D` `F` `J` `K` | 노트 치기 (왼쪽 줄부터 차례로) |
| `SPACE` | 각성 (각인에서 배운 뒤, 게이지가 차면 잠깐 동안 피해 2배) |
| `ESC` | 일시정지 / 메뉴에서 뒤로 |
| `Tab` 또는 `1` `2` `3` | 메뉴 탭 바꾸기 |
| 터치 | 휴대폰·태블릿에서는 줄을 손가락으로 눌러요. 전장을 누르면 각성, 위쪽 Ⅱ 버튼은 일시정지 |

- **긴 노트(롱노트)**는 끝까지 누르고 있다가 떼요. 너무 일찍 떼면 MISS 예요.
- **PERFECT** 일수록, **콤보**가 길수록 더 큰 피해를 줘요. 콤보 50마다 축하 연출이 나와요.
- **보스**는 체력이 절반 아래로 떨어지면 **분노**해요. 노트가 빽빽해지고 공격이 세져요.
- 스테이지를 깨면 **영혼석**을 받아요. 랭크(S·A·B·C)가 높을수록, 처음 깰수록 더 많이 받아요.

## 심연의 탑 (무한 도전)

1장 보스를 쓰러뜨리면 원정 지도 오른쪽 위에 **심연의 탑**이 열려요.
층마다 몬스터 세 마리(5층마다 보스)가 나오고, 위로 갈수록 빠르고 단단해져요.
체력은 다음 층으로 이어지고(층마다 30% 회복), 쓰러질 때까지 몇 층까지 오르는지 기록돼요.

## 메뉴

| 탭 | 내용 |
|---|---|
| 스테이지 | 원정 지도에서 스테이지 12개를 골라요. 앞 스테이지를 깨야 다음 곳이 열려요. |
| 스킬 트리 | 영혼석으로 각인 19개를 새겨요. 공격 · 방어 · 리듬 · 행운 네 갈래. |
| 설정 | 노트 속도, 판정 오프셋(**자동 맞추기**: 딸깍 소리에 맞춰 12번 누르면 계산), 소리 크기, 그래픽(선명하게/빠르게) |

## 원정 지도

| 장 | 스테이지 | BPM | 보스 |
|---|---|---|---|
| 1장 · 버려진 묘지 | 1-1 ~ 1-4 | 100 ~ 112 | 세 눈의 마왕 |
| 2장 · 핏빛 성채 | 2-1 ~ 2-4 | 118 ~ 130 | 심연의 아귀 |
| 3장 · 심연의 균열 | 3-1 ~ 3-4 | 136 ~ 156 | 수정 거인 |

## 몬스터 (도트 그림)

독액 슬라임 · 흡혈 박쥐 · 심연의 촉수 · 바위 골렘 · 망령 · 저주의 눈 · **세 눈의 마왕** · **심연의 아귀** · **수정 거인**

- 몬스터는 35×35(보스 42×42) 칸의 굵은 도트로 그린 뒤 한 칸을 7배로 키워서, 화면에서 약 245~294 픽셀 크기로 보여요. 기사는 28×27 칸을 5배로 그려요.
- 숨쉬기(박자에 맞춰 움직임) · 눈 깜빡임 · 공격 · 맞았을 때 번쩍임 애니메이션이 있고, 쓰러지면 도트가 산산이 흩어져요.

## 만든 방법

- HTML + JavaScript 로 만들었어요. 외부 라이브러리는 쓰지 않았고, 글꼴만 Google Fonts 에서 불러와요 (한글: 나눔명조, 영어: Cinzel).
- **디자인**: 어두운 중세 판타지 색감에, 모양은 각지고 디지털하게 만들었어요. 모서리를 비스듬히 깎은 패널, 눈금, 칸으로 나뉜 게이지, 양끝이 뾰족한 명판, 화면 전체를 감싸는 금테가 있어요.
- **해상도**: 화면을 1.5~2배(최대 2560×1440) 해상도로 그려서 글자와 테두리가 또렷해요.
- **배경**: 그림 파일 없이 코드로 그려요. 1장은 차가운 달빛 아래 묘지와 마른 나무, 2장은 붉은 달 아래 성채, 3장은 하늘이 찢어진 심연이에요. 달빛 줄기, 구름, 안개, 돌바닥이 있어요.
- **웅장한 연출**: 장 시작 타이틀 카드, 보스가 나오면 화면 위아래가 검게 가려지고 징 소리와 함께 이름이 크게 떠요. 승리하면 금빛 빛줄기와 랭크 인장이 나와요. 보스전에는 번개가 치고, 불씨와 재가 날려요.
- **타격감**: 치명타와 격파 순간 화면이 아주 잠깐 멈추고(히트스톱) 크게 흔들려요.
- **살아 있는 전장**: 바닥을 흐르는 안개 두 겹, 젖은 돌바닥에 비친 기사와 몬스터, 일렁이는 화로, 검이 그리는 빛의 궤적, 몬스터에 남는 초승달 베기 자국, 쓰러진 몬스터에서 빠져나와 점수로 날아가는 영혼, 몬스터 초상화 메달이 있어요.
- **화면 장식**: 리듬 줄 뒤로 흐르는 금빛 룬 문자, 금테를 따라 스쳐 가는 빛, 영화 같은 필름 질감. 타이틀에는 달을 가로지르는 구름과 번개, 로고를 쓸고 지나가는 빛이 있어요.
- **음악**: 소리 파일 없이 Web Audio 로 그 자리에서 만들어요. 현악 화음, 합창, 금관, 팀파니, 큰북으로 오케스트라 느낌을 냈어요. 전투 중 멜로디는 노트 악보와 같아서, 노트를 치는 박자가 곧 노래의 멜로디예요.
- **도트 그림**: 타원·막대·다각형을 칠하면 빛 방향을 계산해서 명암 4단계, 바둑판 점(디더링), 테두리, 반대쪽 빛(림 라이트)을 자동으로 넣어요.
- **박자 맞추기**: 소리 장치의 시계로 시간을 재서, 화면이 잠깐 버벅여도 판정이 어긋나지 않아요.
- **렉 줄이기**: 무거운 그림(배경·패널·풍경)은 처음에 한 장으로 미리 그려 두고, 매 프레임에는 움직이는 것만 그려요. 느린 컴퓨터에서는 자동으로 "빠르게" 그래픽으로 바뀌어요.
- 처음에는 자바로 만들기 시작했다가, 판정 정확도·빛 효과·쉬운 실행 때문에 HTML/JavaScript 로 바꿨어요.

## 파일

```
rhythm-fighter/
├─ index.html      ← 이 파일을 열면 게임 시작
└─ js/
   ├─ util.js      ← 색 · 글꼴 · 금테 패널 · 게이지 · 아이콘 · 배경 그리기
   ├─ pixelart.js  ← 도트 그림판, 몬스터 9종, 기사
   ├─ audio.js     ← 박자 시계, 노트 악보, 오케스트라 신시사이저
   ├─ data.js      ← 각인(스킬 트리), 스테이지, 저장
   ├─ fx.js        ← 파티클, 버튼
   ├─ title.js     ← 타이틀 화면
   ├─ hub.js       ← 메뉴 (원정 지도 · 각인 · 설정)
   ├─ battle.js    ← 전투 화면
   └─ main.js      ← 시작점, 입력, 화면 전환
```

## 내 컴퓨터에서 실행하기

이 폴더의 `index.html` 을 더블클릭하면 브라우저에서 바로 열려요. (크롬 또는 엣지 추천)
진행 상황은 브라우저에 저장돼요.

# ⚔️ 검은 서약 (Oathbound)

기사 한 명이 다섯 괴물과 차례로 싸우는 **횡스크롤 2D 도트 액션 보스 러시** 게임이에요.
참격 3연타로 베고, 보스의 공격을 **패링**으로 튕겨 내서 체간을 무너뜨리세요.

**▶ 플레이: https://hyeonseora.github.io/QUEST-TRACK-2/home-projects/oathbound/**

## 하는 방법

| 키 | 하는 일 |
|---|---|
| A D | 이동 |
| W / Space | 점프 (짧게 누르면 낮게) |
| Q | 원거리 참격 — 초승달 검기를 날려요 (기력 1칸) |
| E | 근거리 공격 (누를 때마다 3연타까지) |
| F | 패링 |
| Shift | 대시 (잠깐 무적) |
| R | 포션 (체력 40% 회복) |
| Esc / P | 일시정지 |
| M | 소리 끄기 / 켜기 |

메뉴는 W S (또는 화살표)로 고르고 Enter 로 눌러요. 시작 화면 오른쪽 위에서 **한국어 / English** 를 바꿀 수 있어요.

- 벽 쪽으로 누르면 벽을 타고 미끄러지고, 그때 점프하면 벽을 차고 뛰어요. 공중 대시는 땅에 닿기 전까지 한 번.
- 패링 키를 누르자마자 막으면 **완벽 패링** — 체간이 더 많이 쌓이고 기력도 더 차요.

- 보스가 스킬을 쓰기 직전에 머리 위에 **스킬 이름표**가 떠요. `[패링]` 은 노란색, `[회피]` 는 빨간색이에요.
- 공격 예고: **빗금 칸** = 맞는 범위 (아래 막대가 다 차면 공격), **흐르는 점선** = 탄이 날아올 길, **>>> 띠** = 돌진·충격파가 달려올 방향, 빨간 점선 = 하늘에서 떨어지는 유성·가시의 길.
- **노란 빛**이 번쩍인 공격 → 맞기 직전에 패링하세요. 탄은 보스에게 되돌아가요.
- **붉은 빛과 ! 표시**가 뜬 공격 → 패링이 안 돼요. 대시나 점프로 피하세요.
- 패링하면 보스 체력 아래 **체간**이 쌓여요. 가득 차면 보스가 비틀거리고, 그동안 1.6배 피해를 받아요.
- 근거리 공격을 맞히거나 패링하면 **기력**(3칸)이 차요. 기력 1칸으로 검기를 날리고, 검기는 날아오는 탄도 베어 없애요.
- 패링 직후 1초는 **반격** 시간이라 공격이 더 세고 금빛으로 빛나요.
- 쉬지 않고 계속 베기만 하면 보스가 몸 주위를 터뜨려 반격해요.
- 보스 체력이 절반이 되면 **분노**해서 빨라지고 새 스킬을 써요.
- 보스를 처음 쓰러뜨리면 **축복**(강화) 3개 중 하나를 골라요. 기록은 브라우저에 저장돼요.

게임 화면은 1280×720 으로 그려요. 캐릭터는 도트 그대로 또렷하게, 이펙트는 부드럽고 세밀하게 보여요.

## 보스

| 순서 | 보스 | 전투장 | 스킬 |
|---|---|---|---|
| 1 | 묘지기 해골 | 달빛 묘지 | 할퀴기 연타, 뼈 던지기, 땅속 이동, 도약 내려찍기 / 분노: 뼈 가시 행렬, 해골 졸개 소환 |
| 2 | 등불의 망령 | 무너진 예배당 | 영혼탄 부채꼴, 등불 강하, 분신 돌진, 저주의 원 / 분노: 영혼 소용돌이 |
| 3 | 푸른 악몽마 | 푸른 불꽃의 폐허 | 돌진(패링하면 비틀거림), 앞발 구르기 충격파, 푸른 유성, 도깨비불 / 분노: 3연속 돌진, 불꽃 고리 |
| 4 | 지옥 야수 | 지옥의 문턱 | 화염구, 발밑 불기둥, 불기둥 행진, 화염 숨결, 불꽃 순간이동, 손톱 연타 / 분노: 용암 비 |
| 5 | 가시 드래곤 | 용의 둥지 | 물어뜯기, 내려치기와 낙석, 발밑 짓밟기, 화염 분사, 가시 비, 꼬리 가시 / 분노: 화산 낙하 |

## 파일 구조

```
oathbound/
├─ index.html          ← 화면 뼈대 (메뉴, HUD)
├─ css/style.css       ← 화면 꾸미기
├─ js/
│  ├─ i18n.js         ← 한국어 / English 번역
│  ├─ assets.js        ← 스프라이트 시트 정보, 그림 불러오기, 애니메이션
│  ├─ audio.js         ← 효과음 (Web Audio 로 직접 만든 소리)
│  ├─ input.js         ← 키보드 입력
│  ├─ fx.js            ← 파티클, 칼날 궤적, 빛살, 충격파, 폭발, 순간 확대, 글자
│  ├─ stages.js        ← 전투장 배경 5곳 (코드로 그린 도트 배경)
│  ├─ combat.js        ← 공격 판정, 탄, 충격파, 불기둥, 유성, 기사의 검기
│  ├─ player.js        ← 기사 (이동, 3연타, 검기, 패링, 대시, 포션, 기력)
│  ├─ boss-base.js     ← 보스 공통 뼈대, 체간, 분노, 졸개
│  ├─ bosses.js        ← 보스 5마리와 스킬
│  ├─ ui.js            ← 저장, 축복, 메뉴(화살표로 고르기)·HUD
│  └─ main.js          ← 게임 흐름, 충돌, 그리기
└─ assets/images/      ← 캐릭터·보스 스프라이트 시트
```

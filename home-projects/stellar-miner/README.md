# ⛏️ 스텔라 마이너 (Stellar Miner)

우주에 떠 있는 소행성을 곡괭이로 캐서 크레딧을 모으는 **클리커 게임**이에요.
처음엔 돌 곡괭이 하나로 시작하지만, 채굴 부대를 늘리고 더 깊은 우주로 탐사를 떠나면 은하 엔진까지 손에 넣을 수 있어요.

**▶ 플레이: https://hyeonseora.github.io/QUEST-TRACK-2/home-projects/stellar-miner/**

## 하는 방법

1. 가운데 소행성을 **클릭**해서 크레딧을 캐요.
2. **빠르게 연타**하면 콤보가 쌓여서 최대 6배까지 더 많이 캐요.
3. 모은 크레딧으로 상점에서 **곡괭이**를 강화하고 **채굴 부대**를 사요. 부대는 자동으로 캐 줘요.
4. **탐사**로 더 비싼 소행성으로 옮겨 가요 (모두 10단계).
5. 화면을 지나가는 **황금 혜성**을 클릭하면 7배 부스트나 크레딧 보너스를 받아요.

## 상점 탭

| 탭 | 내용 |
|---|---|
| 부대 | 곡괭이 강화 · 탐사 · 채굴 부대 10종 (x1 / x10 / x100 구매) |
| 연구 | 한 번 사면 영원히 효과가 있는 업그레이드 84개 (부대 2배, 치명타, 콤보, 혜성, 정제소 등) |
| 업적 | 30개. 하나 달성할 때마다 모든 생산 +2% |
| 초신성 | 진행을 처음으로 돌리는 대신 **별 조각**을 얻어요. 조각 하나마다 모든 생산이 영원히 +5% |

## 소행성 10단계

운석 바위 → 구리 → 코발트 → 황금 → 에메랄드 → 다이아몬드 → 별의 심장 → 플라즈마 결정 → 암흑 물질 → 퀘이사 핵

## 채굴 부대 10종

우주 광부 · 플라즈마 드릴 · 채굴 로봇 · 궤도 레이저 · 채굴 모선 · 항성 수확기 · 중력 견인선 · 웜홀 채굴기 · 다이슨 스웜 · 은하 엔진

## 그 밖의 기능

- 숫자를 줄이지 않고 그대로 보여 줘요 (예: `5,203,309,762,905`).
- 진행 상황은 5초마다 브라우저에 자동 저장돼요.
- 창을 닫아 둔 동안에도 채굴 부대가 일해요 (최대 2시간, 연구하면 8시간).
- 오른쪽 위 🔊 버튼으로 소리를 끌 수 있어요.
- 오른쪽 위 ↻ 버튼은 별 조각과 업적까지 **모두 지우고** 처음부터 시작해요.

## 만든 방법

- HTML 파일 하나(`index.html`)로 되어 있어요. 외부 라이브러리는 쓰지 않았고, 글꼴만 Google Fonts 에서 불러와요.
- 그래픽은 모두 Canvas 로 직접 그려요. 소행성은 매번 새 모양으로 만들어지고, 햇빛·그림자·빛나는 결정을 따로 그려서 겹쳐요.
- 효과음은 Web Audio 로 그 자리에서 만들어요 (소리 파일 없음).
- 렉을 줄이려고 빛 번짐 효과는 미리 그려 둔 그림을 재사용하고, 배경 우주는 한 번만 그려요.

## 내 컴퓨터에서 실행하기

이 폴더의 `index.html` 을 더블클릭하면 브라우저에서 바로 열려요.

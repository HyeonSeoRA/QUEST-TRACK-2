# 🏫 제7교시 (The Seventh Period)

> 6교시 수학 시간에 잠깐 엎드려 잤을 뿐인데,
> 눈을 떠 보니 학교는 20년 전에 문을 닫은 **폐교**가 되어 있었다.
> 칠판에는 있지도 않은 「7교시 — 자습. 아무도 나가지 마시오.」

1인칭 **3D 공포 롤플레잉 게임**이에요. 손전등이 되는 휴대폰 하나를 들고 폐교 2층을 탐색하며, 일지를 모아 그날의 진실을 알아내고, 귀신과 싸우고, 출석부를 채우려는 「담임」에게서 살아 나가야 해요.

**▶ 플레이: https://hyeonseora.github.io/QUEST-TRACK-2/home-projects/seventh-period/**

> ⚠️ 갑자기 튀어나오는 얼굴, 큰 비명, 깜빡이는 화면, 피와 불에 관한 묘사가 있어요. (만 15세 이상 권장)
> 키보드와 마우스가 있는 컴퓨터(크롬·엣지)에서 할 수 있어요. 헤드폰을 쓰면 더 무서워요.

## 시작하기

1. **동의**: 이용 약관 · 개인정보 · 공포 표현 · 광과민성 경고에 동의해요. (강한 연출, 로그인 기억은 선택)
2. **로그인**: 구글 계정으로 로그인하거나, 별명을 적고 게스트로 시작해요.
   - 로그인한 이름이 게임 속 주인공 이름이 되고, 진행 기록과 엔딩 기록이 계정마다 따로 저장돼요.
   - 정보는 이 브라우저에만 저장되고 어디로도 보내지 않아요. 이메일은 받지 않아요.
3. **새 학기**를 누르면 이야기가 시작돼요.

## 롤플레잉 요소

- **레벨과 능력 점수**: 귀신을 물리치거나 일지를 읽으면 경험치를 얻어요. 레벨이 오르면 `Tab` 에서 **체력 · 정신력 · 근력 · 지구력** 중 하나를 올려요.
- **네 가지 수치**: 체력, 정신력(귀신을 보거나 어둠 속에 있으면 줄어요. 바닥나면 헛것이 보이고 체력이 깎여요), 기력(달리기·공격), 휴대폰 배터리.
- **무기 4종**: 맨손 → 대걸레 자루 → 쇠파이프 → 소방 도끼 (숨겨진 방에 있어요)
- **소지품**: 붕대, 진정제, 배터리, 소금 봉지
- **촛불 기록**: 촛불 앞에서 `E` 를 누르면 진행이 저장되고 숨을 고를 수 있어요. 죽으면 마지막 촛불에서 다시 시작해요.
- **선택지와 엔딩 3개**: 대화에서 고른 대답과, 숨겨진 물건을 찾았는지에 따라 결말이 달라져요.

| 담임 | 키가 큰 남자, 출석부와 회초리. 번호를 부를 때 **움직이지 말고 불을 끄면** 비틀거린다 |

## 무서운 장치들

- 교실을 나서면 모든 의자가 한꺼번에 문 쪽으로 돌아가 있다
- 손전등 빛 속에서만 보이는 먼지, 깜빡이는 형광등, 붉게 물드는 비상등
- 갑툭튀 얼굴 3종 (텅 빈 눈 / 찢어진 웃음 / 눈 없는 얼굴)
- 정신력이 낮으면 화면이 일그러지고, 곁눈에 헛것이 서 있고, 속삭임이 들린다
- 천장 위를 뛰어가는 발소리, 가까운 문을 두드리는 소리, 혼자 울리는 휴대폰 ("발신자: 31")
- 컴퓨터에 한국어 음성이 있으면 담임이 낮은 목소리로 직접 번호를 부른다

## 만든 방법

- **three.js (r128)** 를 CDN 에서 불러와 3D 로 그려요. 그림·소리 파일은 하나도 없어요.
- 벽, 바닥, 칠판, 사물함, 피 얼룩, 낙서, 얼굴은 모두 캔버스에 **코드로 그린 그림**이에요. 얼굴은 픽셀마다 입체·빛·핏줄을 계산해서 그려요.
- 화면 효과(필름 노이즈, 색 번짐, 비네트, 정신력 왜곡, 피격 효과)는 직접 짠 셰이더로 만들어요.
- 움직이지 않는 소품 700여 개를 재질별로 합쳐서 그리기 횟수를 줄였어요 (부드럽게 돌아가도록).
- 소리는 Web Audio 로 그 자리에서 만들어요 (종소리, 비명, 심장 소리, 피아노, 빗소리).

| 파일 | 내용 |
|---|---|
| `js/config.js` | 구글 로그인 클라이언트 ID |
| `js/audio.js` | 효과음, 배경음, 위치에 따라 좌우로 들리는 소리 |
| `js/textures.js` | 벽·바닥·칠판·얼굴 등 코드로 그리는 그림 |
| `js/world.js` | 학교 지도, 교실 소품, 문, 형광등, 충돌 |
| `js/entities.js` | 귀신 모양과 움직임, 보스 장치 |
| `js/ui.js` | 체력 막대, 대화창, 일지, 소지품 창 |
| `js/story.js` | 일지, 대화, 목표, 장면, 엔딩 |
| `js/game.js` | 플레이어, 전투, 화면 효과, 저장 |
| `js/auth.js` | 동의, 구글 로그인 / 게스트 |
| `js/main.js` | 시작 흐름, 메뉴, 설정 |

## 구글 로그인 켜는 법

지금은 `js/config.js` 의 클라이언트 ID 가 비어 있어서 **게스트로만** 시작할 수 있어요. 구글 로그인을 켜려면:

1. [Google Cloud Console](https://console.cloud.google.com/) → 새 프로젝트 → **API 및 서비스 → OAuth 동의 화면** 설정
2. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 웹 애플리케이션**
3. **승인된 자바스크립트 원본**에 `https://hyeonseora.github.io` 추가
4. 만들어진 클라이언트 ID (`....apps.googleusercontent.com`) 를 `js/config.js` 의 `GOOGLE_CLIENT_ID` 에 넣기

> 클라이언트 ID 는 원래 웹페이지에 공개되는 값이라 넣어도 괜찮아요. **클라이언트 보안 비밀(secret)은 절대 넣으면 안 돼요.**
> 파일을 더블클릭해서 열면(`file://`) 구글 로그인이 안 되고, GitHub Pages 주소에서만 돼요.

# 👻 망령의 미로 (Haunted Maze)

할로윈 기념으로 만든 **공포 미로 탈출 게임**이에요.
손전등 하나만 들고 어두운 미로에서 열쇠를 찾아 탈출구를 열어야 해요. 3단계까지 있고, 단계가 올라갈수록 더 어둡고, 더 넓고, 더 무서워져요.

**▶ 플레이: https://hyeonseora.github.io/QUEST-TRACK-2/home-projects/haunted-maze/**

> ⚠️ 갑자기 튀어나오는 무서운 얼굴, 큰 비명 소리, 깜빡이는 화면이 있어요.

## 하는 방법

1. 미로 어딘가에 있는 **열쇠**를 주워요.
2. 바닥의 **탈출구(뚜껑문)** 로 가면 다음 단계로 내려가요.
3. 오른쪽 위 **미니맵**에 열쇠·탈출구·나·유령 위치가 처음부터 보여요. 길과 벽은 지나간 자리 주변 5x5 칸만 기록돼요.
4. 유령에게 닿으면 목숨이 하나 줄고 시작점으로 돌아가요. 주운 열쇠는 그대로예요. 목숨은 3개예요.
5. 막다른 길은 탈출구 하나뿐이라, 쫓기면 계속 돌아서 도망칠 수 있어요. 대신 유령도 빨라요.

| 키 | 하는 일 |
|---|---|
| 방향키 / WASD | 이동 (걷는 쪽으로 손전등이 향해요) |
| Shift / Space 누르고 있기 | 손전등 방향 고정 (뒷걸음질은 느려요) |
| Esc | 일시정지 |
| M | 소리 끄기 / 켜기 |

## 3단계

| 단계 | 장소 | 달라지는 점 |
|---|---|---|
| 1 | 버려진 저택 | 미로 15×15, 머리카락으로 얼굴을 가린 여자 2명, 손전등이 밝아요 |
| 2 | 폐쇄 병동 | 미로 19×19, 붕대 감은 환자 3명이 더 빠르고 더 멀리서 알아채요, 벽에서 피가 흘러요 |
| 3 | 지하 납골당 | 미로 23×23, 해골 병사 1명, 가장 어둡고 손전등이 가끔 꺼져요. 누렇게 바랜 해골 **"그것"** 은 빛이 닿지 않을 때만 움직여요 |

## 두 가지 모드

| 모드 | 내용 |
|---|---|
| 들어가기 (정규전) | 언제나 같은 미로. 순위표에서 겨뤄요 |
| 오늘의 악몽 | 날마다 미로와 "저주"가 바뀌어요 (짙은 안개 / 굶주린 밤 / 정전 / 핏빛 달 / 고요). 같은 날에는 모두 같은 미로라서 오늘의 순위표에서 따로 겨뤄요 |

## 단계마다 다른 장치

- **1단계 삐걱이는 마루**: 검게 들뜬 널빤지를 밟으면 근처 유령이 그 자리로 몰려와요.
- **2단계 철제 셔터**: 복도 셔터가 4초마다 1.3초 동안 닫혀요. 빨간 불이 깜빡이면 곧 닫혀요. 유령도 못 지나가요.
- **3단계 그것**: 손전등으로 비추는 동안에는 움직이지 못해요.
- **어디서든**: 너무 오래 가만히 있으면 숨소리 → 화면 아래서 손이 기어 올라옴 → 갑툭튀. 빨리 움직여야 해요.

## 점수

- 단계 통과: 1,000 / 2,500 / 5,000점
- 시간 보너스: 기준 시간보다 빨리 나간 1초마다 40 / 80 / 140점
- 끝까지 탈출하면 남은 목숨 하나당 1,500점
- 잡혀도 시간은 계속 흘러요
- 실력 좋은 사람은 3단계 전체를 1~2분 안에 깰 수 있어요

## 공정한 경쟁

- 강화 아이템, 상점, 업그레이드가 **하나도 없어요**.
- 미로 모양, 유령이 나타나는 자리, 함정 위치가 **모두에게 똑같아요** (고정 시드).
- 일시정지하면 화면이 가려져서 미리 살펴볼 수 없어요.
- 순위표는 이 브라우저에 저장돼요. 같은 컴퓨터로 번갈아 하며 겨뤄요.

## 무서운 장치들

- **갑툭튀 얼굴**: 화면 가득 실사풍 얼굴이 튀어나오며 비명이 울려요 (얼굴 4종: 긴 머리 여자, 텅 빈 눈의 아이, 찢어진 웃음, 입이 꿰매진 얼굴). 어둠 저편에 작게 서 있다가 달려들기도 하고, 턱이 빠지듯 입이 벌어지고 화면에 피가 흘러내려요.
- **단계별 소품**: 1단계 초상화는 눈동자가 나를 따라오다 가까이 가면 피눈물을 흘려요. 2단계 휠체어는 내가 안 볼 때만 끼익 하고 굴러가요. 3단계 관은 다가가면 열리며 해골이 노려봐요.
- **핏빛 발자국**: 어둠 저편에서 나를 향해 발자국이 하나씩 찍혀 와요.
- **탈출 직전**: 뚜껑문을 여는 순간 마지막 얼굴이 튀어나와요 ("어디 가?").
- **지직거림 속 얼굴**: 2·3단계 정해진 시각에 화면이 지직거리며 얼굴이 비쳐요.
- **멀리서 들리는 비명**, **등 뒤의 숨소리**
- **벽에서 뻗어 나오는 손**: 가까운 벽 틈에서 앙상한 손이 뻗어 나왔다 들어가요. 유령이 가까울수록 자주 나와요 (잡지는 않아요).
- **꿈틀대는 어둠**: 손전등 빛의 가장자리를 어둠이 도트 덩어리로 갉아먹어요. 심장이 뛸 때마다 화면 가장자리가 조여들어요.
- **미로 꾸미기**: 벽 모서리 명암, 금 간 바닥, 먼지, 구석 거미줄. 1단계 찢어진 벽지와 붉은 카펫, 2단계 떨어져 나간 타일·진료 기록지·깨진 유리·곰팡이, 3단계 쇠사슬·벽 속 해골·물웅덩이·뼛조각.
- **단계별 소리**: 1단계 아이 웃음소리, 2단계 심전도 기계(가끔 길게 멈춤), 3단계 뼈 달그락 소리. 해골은 걸을 때마다 뼈가 달그락거리고, 환자는 다리를 질질 끌어요.
- **정전**: 손전등이 꺼지고 속삭임이 들리다가, 불이 켜지면 바로 앞에 얼굴이 있어요.
- **기어 오는 것**: 어둠 속에서 네 발로 달려들다가 코앞에서 얼굴로 바뀌어요.
- **바라보는 것**: 손전등 끝에 가만히 서 있다가 불이 깜빡하면 사라져요.
- **등 뒤에 선 것**: 발소리가 멈추면 정말로 뒤에 서 있어요. 돌아보면...
- **스쳐 가는 그림자**, **벽을 두드리는 피 묻은 손자국**, **바닥에 나타나는 핏빛 글씨**
- 2단계부터는 손전등이 깜빡이는 찰나에만 보이는 형체가 있어요.
- 겁에 질리면 시야가 두 겹으로 흔들려요.
- 유령이 가까워지면 심장 소리가 빨라지고 화면이 붉게 물들어요.
- 유령이 나를 발견하면 날카로운 비명을 지르고, 쫓기는 동안에는 불협화음이 점점 커져요.
- 유령이 지나가면 근처의 호박등과 촛불이 훅 꺼져요.
- 유령이 아주 가까우면 손전등이 떨리고, 한순간씩 얼굴이 비쳐요.
- 메뉴 화면에서도 번개가 칠 때마다 무언가가 조금씩 다가오고, 달 앞에는 무언가가 매달려 흔들려요.

## 만든 방법

- `index.html` 과 `js` 폴더의 파일들로 되어 있어요. 외부 라이브러리는 쓰지 않았고, 글꼴만 Google Fonts 에서 불러와요.
- 캐릭터·유령·호박·열쇠는 **20×20 도트**로 한 픽셀씩 그렸고, 벽과 바닥은 단계마다 다른 무늬를 계산해서 만들어요.
- 갑툭튀 얼굴과 메뉴 배경은 사진 파일 없이, 픽셀마다 입체감·조명·피부 무늬를 계산해서 **실사처럼** 그려요.
- 손전등은 벽에 막히는 빛(시야 계산)으로 그려서 벽 너머는 보이지 않아요.
- 소리는 Web Audio 로 그 자리에서 만들어요 (소리 파일 없음).

| 파일 | 내용 |
|---|---|
| `js/util.js` | 고정 시드 난수, 노이즈 |
| `js/maze.js` | 미로 만들기, 길 찾기 |
| `js/sprites.js` | 20×20 도트 그림, 단계별 벽·바닥 |
| `js/audio.js` | 비명, 심장 소리, 속삭임, 배경음 |
| `js/realistic.js` | 실사풍 얼굴, 메뉴 배경, 갑툭튀 화면 |
| `js/game.js` | 이동, 손전등, 유령, 이벤트, 점수 |
| `js/main.js` | 메뉴, 화면 전환, 순위표 |

## 내 컴퓨터에서 실행하기

이 폴더의 `index.html` 을 더블클릭하면 브라우저에서 바로 열려요.

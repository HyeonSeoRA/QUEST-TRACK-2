# ⛏️ 마인크래프트 웹 에디션 (week-02)

마인크래프트를 **HTML 파일 하나**로 따라 만든 3D 블록 게임이에요.
설치할 것 없이 브라우저(크롬·엣지)에서 바로 돌아가요.

**▶ 플레이: https://hyeonseora.github.io/QUEST-TRACK-2/week-02/minecraft/**

> 팬이 만든 연습용 클론이에요. Mojang·Microsoft 와는 관련이 없어요.

## 들어 있는 것

- **끝없는 세계**: 평원·숲·사막·눈 덮인 평원·바다·해변·산, 동굴, 광석(석탄·철·금·다이아몬드), 참나무·자작나무, 선인장, 꽃과 풀
- **마인크래프트식 그래픽**: 16×16 픽셀 텍스처, 부드러운 조명과 모서리 그림자(AO), 해·달·별, 낮과 밤(20분), 3D 구름, 반투명 물, 안개
- **빛**: 하늘빛과 횃불·발광석 빛이 블록을 따라 퍼져요 (동굴은 깜깜해요)
- **서바이벌**: 체력·배고픔·숨, 낙하 데미지, 블록 캐는 시간, 도구(나무·돌·철·다이아몬드 곡괭이/도끼/삽)와 내구도, 사과 먹기
- **제작**: 2×2 인벤토리 제작, 3×3 제작대 (판자, 막대기, 제작대, 횃불, 도구, 사암, 석재 벽돌, 책장)
- **크리에이티브**: 모든 블록, 하늘 날기, 바로 부수기
- **물리**: 1초에 20번 계산하는 마인크래프트 방식 (점프, 달리기, 웅크리기, 수영), 떨어지는 모래·자갈
- **화면**: 타이틀, 세계 만들기, 일시정지, 설정(시야 거리·시야각·감도·소리·GUI 크기), F3 디버그 화면
- **저장**: 브라우저에 세계와 인벤토리가 자동 저장돼요

## 조작법

| 키 | 하는 일 |
|---|---|
| W A S D | 이동 |
| 스페이스 | 점프 / 수영 / (크리에이티브) 두 번 누르면 날기 |
| Shift | 웅크리기 (모서리에서 안 떨어져요) |
| W 두 번 빠르게 | 달리기 |
| 왼쪽 클릭 (꾹) | 블록 부수기 |
| 오른쪽 클릭 | 블록 놓기 / 제작대 열기 / 사과 먹기(꾹) |
| 휠 클릭 | (크리에이티브) 보고 있는 블록 집기 |
| 1~9, 휠 | 단축 칸 고르기 |
| E | 인벤토리 |
| Q | 아이템 버리기 |
| F1 / F3 | 화면 정보 숨기기 / 디버그 화면 |
| Esc | 게임 메뉴 |

## 내 컴퓨터에서 실행하기

이 폴더의 `index.html` 을 더블클릭하면 돼요.
글꼴(갈무리)만 인터넷에서 불러오고, 나머지는 전부 파일 안에 들어 있어요.

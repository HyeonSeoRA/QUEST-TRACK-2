# 🎲 운명의 굴림 (RNG)

버튼을 누를 때마다 정해진 확률로 **오라**가 하나 나오는 운 게임이에요.
흔한 먼지(2분의 1)부터, 평생 한 번 볼까 말까 한 창세(10해 분의 1)까지 오라가 모두 20종 있어요.

**▶ 플레이: https://hyeonseora.github.io/QUEST-TRACK-2/week-04/rng/**

## 하는 방법

1. 가운데 **굴리기** 버튼(또는 스페이스·엔터)을 눌러요.
2. 오라가 나오면 그 오라가 귀할수록 코인을 많이 받아요.
3. 지금 가진 것보다 귀한 오라가 나오면 **자동으로 장착**돼요. 장착한 오라의 등급이 높을수록 행운이 올라가요.
4. 모은 코인으로 **상점**에서 물약과 업그레이드를 사서 더 귀한 오라를 노려요.

## 오라 20종과 등급

| 등급 | 오라 (확률) |
|---|---|
| 일반 | 먼지 (1/2) · 이슬 (1/4) · 산들바람 (1/8) |
| 고급 | 불씨 (1/16) · 서리 (1/32) · 번개 (1/64) |
| 희귀 | 비취 (1/128) · 자수정 (1/256) · 태양 (1/1,000) |
| 에픽 | 월식 (1/5,000) · 오로라 (1/25,000) · 심연 (1/100,000) |
| 전설 | 초신성 (1/100만) · 성운 (1/1,000만) |
| 신화 | 블랙홀 (1/1억) · 퀘이사 (1/10억) |
| 우주 | 빅뱅 (1/1조) · 다중우주 (1/1,000조) |
| 초월 | 무한 (1/100경) · 창세 (1/10해) |

에픽 이상이 나오면 화면 전체를 쓰는 특별 연출이 나와요.

## 행운

행운이 2 면 모든 오라가 2배 잘 나와요. 행운은 이렇게 올라가요.

- **장착한 오라**: 고급 +0.1 · 희귀 +0.25 · 에픽 +0.5 · 전설 +1 · 신화 +2 · 우주 +4 · 초월 +8
- **10번째 굴림마다 행운 ×2**, **100번째 굴림마다 행운 ×10**
- **물약**과 **네잎클로버** (아래 상점)
- **하늘 이벤트** (아래)

### 운명 게이지

2,000번 굴리는 동안 에픽 이상이 한 번도 안 나오면, 다음 굴림은 **에픽 이상이 확정**이에요.

## 상점

| 물건 | 효과 | 값 (코인) |
|---|---|---|
| 🍀 행운 물약 | 50번 동안 행운 ×2 | 150 |
| 🧪 강한 행운 물약 | 50번 동안 행운 ×5 | 1,500 |
| ✨ 별빛 물약 | 30번 동안 행운 ×25 | 25,000 |
| 👁️ 신의 물약 | 다음 1번만 행운 ×1,000 | 250,000 |
| 🌌 우주의 물약 | 다음 1번만 행운 ×1,000,000 | 50,000,000 |
| ☘️ 네잎클로버 | 영원히 행운 +0.5 (최대 40단계) | 300부터 점점 비싸짐 |
| ⏳ 모래시계 | 자동 굴리기가 빨라짐 (최대 6단계) | 500부터 점점 비싸짐 |

## 하늘 이벤트

몇 분마다 하늘 이벤트가 찾아와서 잠깐 동안 규칙이 바뀌어요.

| 이벤트 | 효과 | 시간 |
|---|---|---|
| ☄️ 유성우 | 행운 ×3 | 90초 |
| 🌕 붉은 달 | 에픽 이상 확률 ×5 | 75초 |
| 💰 황금 시간 | 코인 ×3 | 90초 |
| 🌙 고요한 밤 | 자동 굴리기 2배 빠르게 | 120초 |
| 🌀 은하 폭풍 (드묾) | 행운 ×10 | 40초 |

## 자동 굴리기

🤖 **자동** 버튼(또는 A 키)을 누르면 알아서 계속 굴려요. ⚙️ **설정**에서 이런 것을 정할 수 있어요.

- 이 등급 이상이 나오면 멈추기 (처음엔 전설 이상)
- 새 오라를 찾으면 멈추기
- 이미 가진 에픽~신화는 연출 짧게
- 정해진 횟수(100 ~ 10,000번)만 굴리기
- 물약이 떨어지면 코인으로 다시 사기

## 도감과 업적

- 📖 **도감**: 지금까지 찾은 오라와 각각 몇 번 나왔는지 볼 수 있어요.
- 🏆 **업적**: 굴린 횟수, 등급별 첫 발견, 도감 채우기, 물약, 이벤트 등 업적 22개가 있어요. 달성하면 코인을 받아요.
- 업적 창에서 굴린 횟수, 가장 귀한 오라, 플레이 시간 같은 통계도 볼 수 있어요.

## 조작

| 키 | 하는 일 |
|---|---|
| 스페이스 / 엔터 | 굴리기 |
| A | 자동 굴리기 켜기 / 끄기 |
| Esc | 열린 창 닫기 |

화면 아래 ⚡ **빠르게** 버튼을 켜면 굴리는 연출이 짧아지고, 🔊 버튼으로 소리를 끌 수 있어요.

## 그 밖의 기능

- 진행 상황은 10초마다, 그리고 굴릴 때마다 브라우저에 자동 저장돼요.
- 주소 끝에 `?demo` 를 붙이면 도감에서 모든 오라 연출을 미리 볼 수 있어요.

## 만든 방법

- HTML 파일 하나와 JavaScript 파일 10개로 되어 있어요. 외부 라이브러리는 쓰지 않았고, 글꼴만 Google Fonts 에서 불러와요.

| 파일 | 하는 일 |
|---|---|
| `data.js` | 오라 목록, 상점, 숫자 표시 |
| `state.js` | 저장과 난수 |
| `game.js` | 행운 계산, 오라 뽑기, 결과 보여 주기 |
| `cinematic.js` | 에픽 이상 오라의 특별 연출 |
| `fx.js` | 반짝이·고리·화면 흔들림 같은 효과 |
| `events.js` | 하늘 이벤트 |
| `autoroll.js` | 자동 굴리기 |
| `achievements.js` | 업적과 통계 |
| `audio.js` | 효과음 (Web Audio 로 그 자리에서 만듦, 소리 파일 없음) |
| `ui.js` | 버튼, 창, 키보드 |

- 브라우저의 `Math.random` 은 아주 작은 확률(10해 분의 1 같은)을 정확히 다루지 못해요. 그래서 `crypto.getRandomValues` 로 난수를 만들고, 아주 작은 확률은 여러 번 나눠서 굴려요.

## 내 컴퓨터에서 실행하기

이 폴더의 `index.html` 을 더블클릭하면 브라우저에서 바로 열려요.
